# 투자

`투자`는 장기 스윙과 데이트레이딩의 판단·실행·복기를 한곳에서 관리하는 로컬 우선 개인 투자 워크스테이션입니다. 프로그램이 종목을 대신 선택하지는 않습니다. 사용자의 판단을 구조화하고, 위험을 계산하고, 결과를 기억하며, 충분한 표본이 쌓였을 때 실제 전략 우위를 보여주는 것이 목적입니다.

현재 버전: **0.9.2-beta** · 기본 통화: **USD** · 지원 환경: **Windows 10/11**

## 제품 원칙

> 판단은 사람이 하고, 시스템은 그 판단을 규율·기억·측정하며 개선한다.

- 계획 당시 정보와 사후 정보를 섞지 않는다.
- 손익보다 의사결정 과정과 재현 가능한 규칙을 함께 기록한다.
- 표본이 부족한 수치는 결론이 아니라 관찰로 취급한다.
- 사용자의 거래 데이터는 기본적으로 로컬 SQLite에 보관한다.
- 가격·경제지표처럼 최신성이 필요한 데이터에만 인터넷을 사용한다.

## 1. 디자인 방향

### 공통 시각 언어

- 검은색에 가까운 저채도 배경, 얇은 경계선, 정보 밀도가 높은 카드 구조를 사용한다.
- 큰 장식보다 숫자·날짜·상태의 위계를 우선한다.
- 통화와 수량은 고정폭 글꼴, 설명은 일반 산세리프 글꼴로 구분한다.
- 수익/상승은 녹색, 손실/하락은 적색으로 유지해 모드 색상과 의미 색상을 혼동하지 않는다.
- 아이콘은 그레이 베이스의 단순한 기록지와 상승선으로 구성하며 작은 크기에서도 실루엣이 유지되어야 한다.

### Swing 모드

- 라임 그린을 포인트 컬러로 사용한다.
- 계획, 포지션 위험, 전략 근거의 중복, 장기 성과를 빠르게 읽는 구조다.
- Today는 전체 자산·활성 포지션·목표 전망·현재 의사결정 데스크와 미국 주요 지표를 요약한다.

### Day 모드

- 검은 배경과 절제된 핏빛 적색을 모드 포인트로 사용한다.
- 손익 색상은 별도로 유지한다.
- 계획을 꾸미기보다 체결 후 기록, 당일 손익, 저널, 전략별 우위 탐색에 집중한다.
- 저널은 종목·3줄 요약·거래일이 보이는 포스트잇 보드로 제공한다.

### Macro Radar

- CPI, PPI, 실업률, 비농업 고용, 신규 실업수당, 소매판매의 최신값과 이전값을 표시한다.
- 최근 한 번의 방향은 단일 화살표, 두 번 연속 같은 방향은 이중 화살표로 표현한다.
- 향후 일정은 오늘을 기준으로 7일만 표시하며, 일정은 위쪽·날짜는 아래쪽에 둔다.
- 미국 동부시간과 한국시간을 함께 표시한다.

## 2. 알고리즘 구현 방향

### 위험과 포지션 크기

- Long 거래는 `Stop < Entry < Target` 구조를 검증한다.
- `1R = (Entry - Stop) × Quantity`로 고정 위험 단위를 계산한다.
- 계좌 위험 한도, 현재 가용 자산, 단일 종목 최대 50% 비중을 모두 통과하는 최소 수량을 제안한다.
- 분할매수 후 평균단가·현재 위험·최대 위험을 다시 계산한다.

### 전략 카탈로그와 통계

- 전략은 Swing/Day 모드와 섹션별 카탈로그로 관리한다.
- 화면에서 숨긴 전략도 실제 거래에 한 번 사용됐다면 과거 거래와 통계에서 삭제하지 않는다.
- 새 전략은 저장 즉시 선택 목록과 전략별 거래 수·승률·평균 손익·Profit Factor 계산에 참여한다.
- 서로 다른 영역의 근거 수와 총 근거 수를 별도로 측정한다.

### 자산과 현금 흐름

- 초기 총자산, 입금, 출금, 실현손익을 시간순 원장으로 합성한다.
- 입출금을 투자수익으로 오인하지 않도록 순수 성과 계산에서 분리한다.
- 자산 변화, YTD 수익률, 목표 금액 도달 시나리오는 보장값이 아닌 관찰·추정치로 제공한다.

### 시장 가격

- 기본 공급자는 Yahoo Finance를 사용하는 yfinance이며, 설정에서 Alpaca historical SIP로 전환할 수 있다. 두 방식 모두 장중 호가가 아닌 완료된 미국장 일봉 종가를 저장한다.
- 무료 Basic 계정의 SIP 조회 제한을 고려해 현재 시점보다 최소 15분 이전의 완료 일봉만 요청한다.
- 앱 시작 시 활성 포지션 가격을 자동 갱신한다. 네트워크 실패 시 마지막 정상 저장값을 유지한다.
- 종목별 비교는 해당 포지션 진입일부터 섹터 대표주와 SPY를 비교한다.
- 전체 성과는 프로그램의 공통 기준일부터 포트폴리오와 SPY·QQQ를 비교한다.

### Exit Quality

- 매도 당시 가격 구조·모멘텀·시장 환경·심리·재량 근거를 저장한다.
- 종료 후 1·5·10·20 거래일, MFE·MAE를 관찰한다.
- `Chicken-out 가능성`은 심리적 단정이 아니라 구조 훼손 없이 재량 매도했고 이후 의미 있는 상승이 관찰될 때 발생하는 복기 신호다.

### 경제지표

- 최신 관측값은 FRED, 발표 일정은 BLS와 Federal Reserve 공식 일정을 우선한다.
- CPI/PPI를 연준의 2% PCE 목표와 직접 동일시하지 않는다.
- 외부 일정 서버가 차단될 때는 검증된 공식 일정 캐시를 사용한다.

## 3. 기능 및 핫픽스 현황

### 구현 완료

- Swing Today, Trade Planner, Import Position, Positions, Journal, Analytics
- Day Today, Trade Record, Journal, Analytics
- Swing/Day 전략 추가·숨김·복원과 과거 전략 보존
- Planner와 Import Position의 공통 Swing 전략 카탈로그
- 포지션 추가매수·일부매도·손절 변경·전체 종료와 실행 근거 기록
- Initial 1R, Live Risk, Peak Live Risk, 실현손익
- 입출금 원장과 자산 변화 그래프
- 섹터 대표주·SPY 상대수익률
- 미국 주요 지표 및 7일 이벤트 레이더
- Day 전략별 승률·평균손익·Profit Factor와 0선 손익 그래프
- 프로그램 창 종료 시 로컬 서버 종료

### 주요 핫픽스

- PowerShell 실행 정책 없이 실행되는 `start.cmd` 제공
- 브라우저보다 서버가 늦게 시작되어 발생하던 연결 거부 대응
- 잔류 서버가 존재하면 정상 서버를 재사용해 새 창을 여는 런처 보정
- 소수점 둘째 자리 입력·표시 보정
- 단일 자산 기록에서도 날짜/자산 축이 유지되도록 그래프 보정
- Import Position이 Today 활성 포지션에 집계되지 않던 문제 수정
- Day 모드의 빈 손익률 `null` 렌더링 오류와 탭 전환 수정
- yfinance를 기본 시장 데이터 provider로 설정하고 Alpaca historical SIP를 선택형 provider로 유지
- Alpaca를 선택한 경우에만 Windows DPAPI 암호화 API 키 저장 사용
- 첫 실행 API 발급 안내를 탭·버튼별 5페이지 앱 사용 설명서로 교체
- 앱 시작 시 완료 종가 자동 갱신 추가

## 데이터 저장과 개인정보

소스 실행에서는 `data/workstation.db`, 설치 버전에서는 `%LOCALAPPDATA%\투자\data\workstation.db`에 저장된다. Git 저장소와 설치 업데이트에는 개인 거래 데이터가 포함되지 않는다.

백업할 때는 앱을 종료하고 `workstation.db`를 복사한다. 프로그램 업데이트나 Git 브랜치 전환은 이 데이터베이스를 삭제하지 않는다.

자세한 데이터 처리 범위는 [PRIVACY.md](PRIVACY.md), 보안 문제 제보와 로컬 API 보호 방식은 [SECURITY.md](SECURITY.md)를 참고한다.

## Windows 실행 및 설치

GitHub Releases에서 `Tuja-Setup-0.9.2-beta.exe`를 내려받아 설치한다. 설치 후 시작 메뉴와 바탕화면의 `투자` 아이콘으로 실행한다.

소스 실행:

```powershell
git clone https://github.com/Dr-Silvan/Investment-Alpha.git
cd Investment-Alpha
python -m pip install -r requirements.txt
.\start.cmd
```

Python 3와 Microsoft Edge가 필요하다. 설치 패키지는 Python 런타임을 포함하지만 현재 UI 호스트로 Microsoft Edge를 사용한다.

### 시장 데이터와 사용 설명서

처음부터 API 키 없이 yfinance를 통해 완료된 미국장 일봉을 조회한다. 우측 상단 톱니바퀴의 시장 데이터 설정에서 Alpaca historical SIP로 전환할 수 있으며, 이때만 API Key ID와 Secret Key가 필요하다. Alpaca 키는 `workstation.db`나 Git 저장소가 아닌 Windows DPAPI 암호화 파일에 저장된다.

톱니바퀴 옆 책 아이콘은 앱 사용 설명서를 연다. Swing과 Day의 각 탭, 주요 버튼, 데이터 백업 위치를 다섯 페이지로 나누어 안내하며 언제든 다시 열 수 있다.

배포 설치 파일을 직접 빌드하려면 Python 3.10 이상, `requirements-dev.txt`, Inno Setup이 필요하다. Python이나 Inno Setup이 기본 경로에 없다면 각각 `TUJA_PYTHON`, `ISCC_PATH` 환경 변수로 실행 파일을 지정할 수 있다.

공개 서명 빌드는 Windows 인증서 저장소의 코드 서명 인증서 SHA-1 지문을 `TUJA_SIGN_CERT_SHA1`에 설정하고 `TUJA_REQUIRE_SIGNING=1`로 실행한다. 빌드 스크립트는 앱과 설치 파일을 SHA-256으로 서명하고 DigiCert 타임스탬프를 적용한 뒤 서명 상태가 `Valid`인지 검사한다.

## Apple 디바이스 이식 방향

Windows 구현의 데이터·도메인 로직과 UI 호스트를 분리하는 것이 우선이다.

1. SQLite 스키마와 계산 규칙을 플랫폼 독립 코어로 고정한다.
2. 가격·FRED·BLS·Fed 연결부를 명시적인 provider 계층으로 분리한다.
3. 날짜는 UTC 저장, 거래소 시간대와 사용자 표시 시간대를 분리한다.
4. macOS에서는 로컬 백엔드와 WKWebView 또는 네이티브 SwiftUI 셸을 검토한다.
5. iPhone/iPad는 데스크톱 DB 직접 공유보다 암호화된 동기화·충돌 규칙을 먼저 설계한다.
6. 앱 샌드박스의 Application Support에 DB를 저장하고 Keychain에는 인증정보만 둔다.
7. 메뉴바, 창 종료 lifecycle, 백그라운드 갱신은 macOS/iOS 정책에 맞게 별도 구현한다.
8. 기능 동등성보다 Today 확인·저널 입력·위험 알림 같은 모바일 핵심 흐름을 우선한다.
